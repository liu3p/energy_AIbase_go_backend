# 历史数据查询接口 `/his/query`

## 接口概述

用于查询 InfluxDB 中的历史数据，支持根据测点类型和测点 ID 批量查询指定时间范围内的数据，并支持时间插值。

## 基本信息

- **路径**: `/api/v1/log/influxdb/his/query`
- **方法**: POST
- **Content-Type**: application/json
- **认证**: 需要 JWT Token

## 请求参数

```json
{
  "type": "analog",
  "ids": ["1-1-102-1", "1-1-102-2"],
  "start_time": "2026-01-01T00:00:00Z",
  "end_time": "2026-01-02T00:00:00Z",
  "interval": 300
}
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | 是 | 测点类型：`digital` 遥信、`analog` 遥测、`pulse` 遥脉 |
| ids | []string | 是 | 测点 ID 数组，至少 1 个，支持批量查询 |
| start_time | string | 是 | 开始时间，RFC3339 格式（如 `2026-01-01T00:00:00Z`） |
| end_time | string | 是 | 结束时间，RFC3339 格式，必须晚于 start_time |
| interval | int | 否 | 时间间隔（秒），默认 300 秒（5分钟），最小 300 秒 |

### 测点类型说明

| type 值 | 类型名称 | InfluxDB Measurement | 聚合函数 |
|---------|----------|---------------------|----------|
| digital | 遥信 (Digital) | digital | last（取窗口最后状态） |
| analog | 遥测 (Analog) | analog | mean（取平均值） |
| pulse | 遥脉 (Pulse) | pulse | mean（取平均值） |

### 测点 ID 格式

测点 ID 格式：`xxx-xxxxx-xxx-xxx`

- 第三段数字必须与请求的 `type` 匹配
- 示例：`1-1-102-1`（遥测类型）

## 响应格式

### 成功响应 (200)

```json
{
  "code": 200,
  "data": [
    {
      "time": "2026-01-01T00:00:00Z",
      "data": {
        "1-1-102-1": 32.4,
        "1-1-102-2": 750.1
      }
    },
    {
      "time": "2026-01-01T00:05:00Z",
      "data": {
        "1-1-102-1": 32.5,
        "1-1-102-2": 750.2
      }
    }
  ],
  "msg": "查询成功"
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，200 表示成功 |
| data | []QueryHistoryDataItem | 时间点数组，按时间升序排列 |
| data[].time | string | 时间点，RFC3339 格式 |
| data[].data | map | 该时间点各测点的值 |
| msg | string | 提示信息 |

### 数据精度

- **遥信 (digital)**: 结果取整数
- **遥测 (analog) / 遥脉 (pulse)**: 保留三位小数

### 错误响应

```json
{
  "code": 400,
  "message": "参数错误: 参数 Type 无效，仅支持 digital(遥信)、analog(遥测)、pulse(遥脉)"
}
```

常见错误：
- `400`: 参数格式错误或缺失
- `500`: 服务器内部错误

## 使用示例

### 查询遥测数据

```bash
curl -X POST http://localhost:8080/api/v1/log/influxdb/his/query \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <your_token>" \
  -d '{
    "type": "analog",
    "ids": ["1-1-102-1"],
    "start_time": "2026-01-01T00:00:00Z",
    "end_time": "2026-01-01T12:00:00Z",
    "interval": 600
  }'
```

### 查询遥信数据

```json
{
  "type": "digital",
  "ids": ["1-1-101-1", "1-1-101-2"],
  "start_time": "2026-01-01T00:00:00Z",
  "end_time": "2026-01-02T00:00:00Z"
}
```

## 技术实现

- **数据源**: InfluxDB 2.x
- **查询语言**: Flux
- **时间插值**: 使用 `aggregateWindow` + `fill(usePrevious: true)` 实现
- **并发控制**: HTTP 连接池，最大 100 空闲连接
- **超时设置**: 查询超时 30 秒

## 相关接口

- `POST /api/v1/log/influxdb/his` - 导出历史数据到 CSV 文件
- `POST /api/v1/log/influxdb/his/home` - 首页历史数据查询（自动从配置读取 OID）

# 首页历史数据查询接口 `/his/home`

## 接口概述

自动从首页配置（`HomepageConfig`）中读取 Topology 和 PowerLevel 的 OID，按类型分组后批量查询 InfluxDB 历史数据，一次性返回两个维度的历史数据。

## 基本信息

- **路径**: `/api/v1/log/influxdb/his/home`
- **方法**: POST
- **Content-Type**: application/json
- **认证**: 需要 JWT Token

## 请求参数

```json
{
  "start_time": "2026-01-01T00:00:00Z",
  "end_time": "2026-01-02T00:00:00Z",
  "interval": 300
}
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| start_time | string | 是 | 开始时间，RFC3339 格式 |
| end_time | string | 是 | 结束时间，RFC3339 格式，必须晚于 start_time |
| interval | int | 否 | 时间间隔（秒），默认 300 秒，最小 300 秒 |

## 响应格式

### 成功响应 (200)

```json
{
  "code": 200,
  "data": {
    "topology": [
      {
        "time": "2026-01-01T00:00:00Z",
        "data": {
          "1-1-102-1": 32.4,
          "1-1-102-2": 750.1
        }
      }
    ],
    "power_level": [
      {
        "time": "2026-01-01T00:00:00Z",
        "data": {
          "1-1-102-3": 10.5
        }
      }
    ]
  },
  "msg": "查询成功"
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，200 表示成功 |
| data.topology | []QueryHistoryDataItem | 拓扑维度的历史数据 |
| data.power_level | []QueryHistoryDataItem | 电力等级维度的历史数据 |
| data.*[].time | string | 时间点，RFC3339 格式 |
| data.*[].data | map | 该时间点各测点的值 |
| msg | string | 提示信息 |

## 处理逻辑

1. 读取 `HomepageConfig`，分别收集 `topology` 和 `power_level` 数组中绑定了 OID 的条目
2. 按 OID 第三段（tableNo）识别测点类型（101=digital, 102=analog, 105=pulse）
3. 对每种类型调用 `QueryHistoryData` 查询 InfluxDB
4. 按 Topology 和 PowerLevel 两个维度组装响应返回

> 注：单类型查询失败不阻塞其他类型，失败的类型结果中不含该类型数据。

## 错误响应

```json
{ "code": 400, "message": "参数 start_time 和 end_time 必填" }
{ "code": 400, "message": "start_time 必须早于 end_time" }
{ "code": 500, "message": "获取首页配置失败: ..." }
```
