# 技术要点

> 项目开发和维护中需要特别注意的技术细节

## 构建与部署

### Cgo 编译

```bash
CGO_LDFLAGS="-L${ARM_SF}/lib/scada -L${ARM_SF}/lib" go build -o arm-web-backend
```

- 目标平台: **ARM 嵌入式 Linux** (Debian)
- 依赖 C++ 库: scada 相关库

### 前端嵌入

```go
//go:embed dist/*
var webFS embed.FS
```

前端构建产物通过 `go:embed` 打包进二进制，不需要单独部署静态资源。

## 编码处理

录波文件可能使用 GBK 编码，代码中做了完整的 GBK↔UTF-8 转换：

```go
func utf8Str2gbkStr(utf8Str string) string  // UTF-8 → GBK
func gbkStr2utf8Str(gbkStr string) string   // GBK → UTF-8
func gbk2utf8(data []byte) []byte           // GBK → UTF-8 字节
func utf82gbk(data []byte) []byte           // UTF-8 → GBK 字节
```

## JSON 库选择

使用 `goccy/go-json` 替代标准库 `encoding/json`，性能更好：

```go
import "github.com/goccy/go-json"
```

## 日志系统

使用 `go.uber.org/zap` + `lumberjack` 实现日志轮转：

```go
import (
    "go.uber.org/zap"
    "gopkg.in/natefinch/lumberjack.v2"
)
```
