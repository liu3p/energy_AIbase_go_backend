# 用户认证体系

> 涉及模块: `middleware/` `handlers/users.go` `emsxmldb/userxml.go`

---

## 认证架构

```
登录请求 → LoginUser handler
         ↓
    emsxmldb.Login() → 读取 XML 文件校验用户
         ↓
    生成 JWT Token (Access + Refresh)
         ↓
    存入 OnlineUsers (sync.Map)
         ↓
后续请求 → middleware.Auth() → 校验 JWT → 注入 UNameKey
```

---

## 用户角色

| 角色常量 | 值 | 说明 |
|---|---|---|
| `UserTypeAdmin` | admin | 超级管理员（硬编码密码 `superman`） |
| `UserTypeConfig` | config | 配置人员 |
| `UserTypeOper` | ops | 运维人员 |
| `UserTypeMonit` | guest | 访客 |

**admin 特殊逻辑**：admin 用户密码固定为 `superman`，不走 XML 校验，直接硬编码验证。

---

## 登录流程 (`LoginUser`)

1. 解析请求体 `LoginReq{Uname, Pwd}`
2. 区分 admin/普通用户走不同校验路径
3. 校验通过后检查**在线冲突**：
   - 若已在线（State=2）→ 返回 409 Conflict
   - 若已登录但不在线（State=1）→ 踢出旧会话
4. 调用 `middleware.GetToken()` 生成 JWT
5. 存入 `OnlineUsers`，返回 Token

---

## Token 机制

```go
// middleware/authentication.go
func GetToken(userInfo *models.UserInfo) (token string, expTime int64, refreshToken string, refreshExpTime int64, err error)
```

- **AccessToken**: 短期有效，用于 API 请求认证
- **RefreshToken**: 长期有效，用于刷新 AccessToken
- 认证中间件: `middleware.Auth()` 从 Header 或 Query 参数提取 JWT

---

## 在线用户管理

```go
var OnlineUsers sync.Map  // key: uname, value: *OnlineUser
```

- 登录时写入
- WebSocket 连接时更新 State=2，存储 PushConn
- WebSocket 断开时更新 State=1，清除 PushConn
- 踢人时通过 `KickOutWsByUname` 发送 WebSocket close 消息

## Session 配置 (`main.go`)

```go
store := cookie.NewStore([]byte("localwebserver"))
store.Options(sessions.Options{
    HttpOnly: true,
    MaxAge:   3600,   // 1 小时
    Path:     "/",
})
```

> **注意**: 虽然配置了 cookie session，实际认证主要通过 JWT Token 实现。

## 安全注意点

- admin 密码硬编码为 `superman`，**生产环境应修改**
- WebSocket `CheckOrigin` 直接返回 `true`，未做跨域限制
- `OnlineUsers` 使用 `sync.Map`，密码明文存储在内存中
