# 项目架构总览

> **模块名**: `webserver-arm` | **Go 版本**: 1.24 | **端口**: :38080

嵌入式 EMS（能量管理系统）的 **LocalWeb 后端服务**，运行在 Debian 嵌入式设备上，为前端 Web UI 提供 REST API + WebSocket 推送。

---

## 启动流程

`main.go` → 初始化日志 → 加载数据文件 → 创建 EMS RPC 客户端管理器 → 启动 Gin HTTP 服务 → 加载前端资源（embed 嵌入）→ 注册路由 → 监听 :38080

---

## 目录结构与模块职责

```
arm-web-backend/
├── main.go              # 入口，加载数据、初始化 EMS 客户端、启动 HTTP
├── routes/              # 路由注册（Gin）
├── handlers/            # 业务处理层（HTTP handler）
├── middleware/          # JWT 认证中间件
├── models/              # 数据模型定义
├── emsclient/           # EMS 核心 RPC 客户端（TCP 长连接）
├── emsdb/               # InfluxDB + 用户数据库操作
├── emsxmldb/            # XML 配置文件读写（RTU/设备/测点/用户/FE配置）
├── emsdatahub/          # 实时数据流 hub（WebSocket 推送）
├── agcconfig/           # AGC（自动发电控制）策略与设备模型配置
├── systeminfo/          # 系统信息获取（网络配置、CPU/内存/磁盘）
├── cgolibparse/         # Cgo 桥接层（调用 C++ 库做公式解析/AGC 计算）
├── zmq/                 # ZMQ 客户端（与 EMS 核心进程消息通信）
├── scdnet/              # SCD 网络相关 API
├── gormsg/              # Redis 客户端封装
├── config/              # 应用配置管理
├── log/                 # zap 日志封装（lumberjack 轮转）
├── utils/               # 工具函数
├── dist/                # 前端构建产物（通过 go:embed 嵌入）
├── data/                # 运行时数据文件（i18n、dataunit、loginrecord 等）
├── paramter/            # C++ 参数枚举工具
├── test/                # 测试客户端
└── docs/                # Swagger 文档 + Obsidian 笔记
```

## 关键数据流

| 数据流 | 路径 | 说明 |
|---|---|---|
| 用户登录 | `LoginUser` → `emsxmldb.Login` → JWT Token | 用户信息存于 XML 文件 |
| 查询遥测遥信 | `handler` → `emsclient.QueryYC/YX` → EMS RPC | TCP 二进制协议 |
| WebSocket 推送 | `Manager.PushMsg` → `PushWs` → 前端 | 实时数据推送 |
| AGC 策略 | `agcconfig` → XML 读写 → Cgo 公式解析 | 策略配置持久化 |
| 系统监控 | `zmq.ZmqClient` → 系统监控进程 | ZMQ DEALER/SUB 模式 |
| 录波文件 | `faultrecording.go` 解析二进制文件 | GBK/UTF-8 编码转换 |

## 技术栈

- **HTTP 框架**: gin-gonic/gin
- **认证**: JWT (`golang-jwt`) + Cookie Session (`gin-contrib/sessions`)
- **实时通信**: gorilla/websocket
- **RPC**: 自定义 TCP 二进制协议（13 字节头 + body）
- **消息队列**: ZeroMQ (`pebbe/zmq4`)
- **时序数据库**: InfluxDB (`influxdata/influxdb-client-go`)
- **日志**: zap + lumberjack（轮转）
- **配置**: XML 文件（`encoding/xml`）+ INI 文件（`go-ini/ini`）
- **Cgo**: 桥接 C++ 库（公式解析、FES 通道消息处理）
- **文档**: Swagger (`swaggo/swag`)
- **JSON**: `goccy/go-json`（高性能 JSON 库）
- **Excel**: `excelize/v2`（测点导入导出）
